# Java Beginner Projects 🚀

A personal collection of beginner-friendly Java projects created while learning and practicing core Java concepts. This repository focuses on hands-on learning through simple, practical programs.

# 🎯 Purpose

Practice Java fundamentals

Strengthen object-oriented programming (OOP) concepts

Build logical thinking through small projects

Maintain a structured learning record on GitHub

# 📂 Projects Included

Tic-Tac-Toe – Two-player console game

Slot Machine Game - Basic randomization and balance 

Student Grade Calculator - Calculate grade based on marks

(More projects will be added as learning progresses.)

# 🧠 Topics Covered

Variables and Data Types

Conditional Statements

Loops

Methods & Functions

Classes and Objects

Encapsulation and OOP basics

User Input handling

# ▶️ How to Run
Clone the repository:- 
git clone https://github.com/Gattik123/java-beginner-projects.git

Navigate to a project folder:- 
cd java-beginner-projects/ProjectName

Compile:- 
javac Main.java

Run:- 
java Main

# 🛠 Requirements

Java Development Kit (JDK 8 or above)

Any Java IDE or editor (IntelliJ IDEA, Eclipse, VS Code)
